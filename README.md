# ERLİK — Release Channel

This repository is the **public release channel** for [ERLİK](https://erlik.be), a native macOS activity, focus and AI-agent time tracker. It hosts prebuilt packages and release notes only. The source code is private.

## Install / update (Homebrew)

```bash
brew tap halilertekin/tap
brew install erlik
erlik start
```

Updates: ERLİK checks this repository's latest release and shows an update dialog when a new version is out. You can also run `brew upgrade erlik`.

The Mac App Store edition updates through the App Store.
