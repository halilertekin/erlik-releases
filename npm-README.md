# ERLİK

Native macOS (Apple Silicon) activity, focus and AI-agent time tracker. Data stays on your Mac.

```bash
npm install -g erlik
erlik start        # erlik stop · erlik status · erlik autostart
```

Dashboard: http://localhost:5757

New versions install from inside the app (signed updates). Homebrew is the recommended install:

```bash
brew tap halilertekin/tap && brew install erlik
```

Clipboard HUD and AI-agent intelligence are Pro features (license key): https://erlik.be
Releases: https://github.com/halilertekin/erlik-releases
